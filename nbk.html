ISS‑25 Explorer

الرئيسية الحياة علي متن iss التتبّع الحيّ قبة المحطة

فريق ISS-25 Explorer

عرض تقديمي يوضح توزيع المهام بين أعضاء الفريق الستة

نظرة عامة على المشروع

ISS-25 Explorer هو موقع ويب تفاعلي بمناسبة مرور 25 عامًا على إنشاء محطة الفضاء الدولية. يتميز الموقع بتصميم عصري، واجهة مستخدم ثنائية اللغة (العربية والإنجليزية)، وتتبع حي لموقع المحطة، بالإضافة إلى محتوى غني عن الحياة على متنها.

فريق العمل

Fathy
مطور واجهة أمامية وتصميم

المهام المنفذة:

  • تصميم واجهة المستخدم الرئيسية باستخدام Tailwind CSS
  • تطبيق نظام التصميم الزجاجي (Glassmorphism)
  • تنفيذ نظام التبديل بين الوضع الليلي والنهاري
  • تحسين تجربة المستخدم للعرض على الأجهزة المختلفة
  • تصميم وتنفيذ صفحة "الحياة على متن المحطة"
Moaz
مطور خرائط وتتبع

المهام المنفذة:

  • دمج خريطة Leaflet.js لتتبع موقع المحطة
  • ربط API موقع المحطة الدولي (wheretheiss.at)
  • تنفيذ حساب مسار المحطة باستخدام satellite.js
  • إنشاء علامة تفاعلية للمحطة مع تأثيرات بصرية
  • إضافة طبقات خرائط مختلفة للوضع الليلي والنهاري
Abdallah
مطورة محتوى وترجمة

المهام المنفذة:

  • تطوير نظام الترجمة ثنائي اللغة (العربية/الإنجليزية)
  • ترجمة جميع النصوص والمحتوى للغة العربية
  • كتابة محتوى صفحة "الحياة على متن المحطة"
  • إعداد الخط الزمني التفاعلي للمحطة
  • ربط API ناسا لاسترجاع الصور والمحتوى
Hitham
مطورة تجارب تفاعلية

المهام المنفذة:

  • تنفيذ عارض القبة البانورامية (Cupola) باستخدام Three.js
  • إضافة عناصر التحكم في العارض البانورامي
  • دمج فيديو البث المباشر من المحطة
  • تحسين أداء التطبيق وسرعة التحميل
  • إضافة تأثيرات بصرية وتحسينات للواجهة
Mr.Ansary
مدير مشروع ومراجع

المهام المنفذة:

  • تخطيط هيكل المشروع وتوزيع المهام
  • مراجعة الكود وضمان جودته
  • اختبار الوظائف والتأكد من عملها المتكامل
  • حل مشاكل التكامل بين مكونات المشروع
  • إعداد التوثيق النهائي للمشروع
Kareem
مصمم تجربة المستخدم

المهام المنفذة:

  • تصميم تجربة المستخدم وتحسين سلاسة التصفح
  • إجراء اختبارات سهولة الاستخدام
  • تحليل سلوك المستخدم وتحسين التصميم
  • تطوير نظام التنقل بين الصفحات
  • تحسين الوصولية للمستخدمين ذوي الاحتياجات الخاصة
